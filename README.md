# 💜 Calculadora Java

Uma calculadora simples desenvolvida em Java como projeto de estudo e portfólio.

O projeto foi desenvolvido utilizando conceitos básicos da linguagem Java, como variáveis, métodos, estruturas condicionais e `switch`.

## ✨ Funcionalidades

- ➕ Soma
- ➖ Subtração
- ✖️ Multiplicação
- ➗ Divisão
- ⚠️ Verificação de divisão por zero
- 🔢 Entrada de números pelo teclado
- 📋 Menu de opções no terminal
- 
## 📚 Conceitos de Java utilizados

- Variáveis e tipos de dados (`double` e `int`)
- Entrada de dados com `Scanner`
- Operadores matemáticos
- Estrutura condicional `if/else`
- Estrutura de decisão `switch/case`
- `System.out.println()` e `System.out.print()`
- Tratamento de divisão por zero
- Organização básica de uma classe Java

## 🧮 Exemplo de execução

```text
================================
       CALCULADORA JAVA
================================

Digite o primeiro número: 10
Digite o segundo número: 5

Escolha uma operação:
1 - Soma
2 - Subtração
3 - Multiplicação
4 - Divisão

Digite a opção: 1
Resultado: 15.0
```
